Full class and method documentation is generated directly from source and
hosted by each language ecosystem's own standard tooling — not duplicated
here, so it never drifts out of sync with what's actually published.

## Rust

documentation will be available automatically at
[docs.rs](https://docs.rs/) under the published crate name.
